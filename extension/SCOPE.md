# Scope — §13, as of 2026-08-24

§13 is the product spec's scope section. Its text lives outside this repo;
what follows is the extension's half of it, rewritten against the code that
actually ships today rather than against what was planned. Where the two
disagree, **the code is the evidence and this file is the record** — every
line below was checked by counting call sites, not by remembering.

The reason this file exists: four features grew in during the notification
work and §13 was never revised, so the spec and the product had quietly
drifted apart. A scope section nobody updates stops being a constraint and
becomes folklore.

### Followed trades shipped default OFF, and is ON since 2026-08-31

It shipped OFF with an END CONDITION rather than as a permanent cut: social
proof needs proof, and with the user base of the day a reader who turned it
on subscribed to an empty room, so shipping it ON would have spent a
notification permission to deliver nothing. The stated trigger was "real
activity to reflect", and the owner called it.

What makes it safe to arrive uninvited is not the switch, it is
`followTrades`' rulebook: a $10 dust floor (below that it is a tap, not a
conviction), ONE ping per asset per hour, and sells that only speak to
somebody who HOLDS the thing. A reader who wants silence has the same one
switch in Settings every other kind has.

Mechanically, `NOTIFY_DEFAULTS.social` is the whole decision, because
`readNotifyPrefs` falls back to each kind's default for an absent key. That
second half is what makes it one line: the read path used to treat any
absent key as "on", so changing the default alone would have moved the
Settings toggle's first paint and nothing else while the background did its
own thing.
